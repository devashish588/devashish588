## Featured projects

### 🔎 [RAG Document Search](https://github.com/devashish588/RAG-Doc-Search)
A retrieval-augmented document question-answering system built with **FastAPI, LangChain, embeddings, and ChromaDB**.

- Implemented document ingestion and semantic retrieval.
- Evaluated retrieval quality: **Recall@1 0.78 · Recall@5 1.00 · Recall@10 1.00 · MRR 0.8867** on the project evaluation set.
- Explored hybrid retrieval and retrieval-quality improvements.

### ⚡ [Applyr](https://github.com/devashish588/Applyr)
An AI-assisted career application platform designed to help users discover opportunities and streamline application workflows.

- LLM-assisted workflows and resume/job information processing.
- Integrations and automation-oriented product architecture.
- Focus on making repetitive career tasks more efficient.

### 🔥 [StudyForge](https://github.com/devashish588/StudyForge)
A personal study and career operating system for organizing learning goals, daily plans, practice, and revision.

- Capacity-aware daily planning and progress tracking.
- Built as a modern web application with an installable PWA experience.

### 🏋️ [FuelUp](https://github.com/devashish588/FuelUp)
A fitness and nutrition tracking application with a local-first approach.

- Structured workout, nutrition, and habit tracking.
- Offline-friendly application architecture.

### 🛠️ [Predictive Maintenance](https://github.com/devashish588/Predictive_Maintenance)
A machine-learning project using NASA turbofan sensor data to explore equipment failure prediction, feature engineering, and model evaluation.
